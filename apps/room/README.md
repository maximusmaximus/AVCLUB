# @avclub/room

Paired desktop screen.

## Behavior
- Admin pairs desktop with access code; re-pair required per event
- Auto-reconnects for event duration on connection drop
- Status running / downtime → sponsor logo (full-res JPEG, optimized per viewport) or background video with pending participant info overlaid
- During event → what's now + countdown to what's coming
- Self-running timer if admin mobile drops offline
- Party Time phase → forward to drawing.grok.me
