# @avclub/admin

Admin dashboard.

## Surfaces
- Interactions tracker (all user interactions)
- Donations tracker (exact amounts)
- Refund retry status (automatic retry on failure)
- Email create/send tracking
- Steward management (separate login, per-Steward revoke)
- Sponsor ad approval queue (disapprove → resubmit flow)
- Payment config (credit card, Apple Pay, Google Pay, x402 wallet address)
- Crypto wallet address display
- Multi-admin control (two admins can control same event)
