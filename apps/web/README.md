Public-facing site.

## Surfaces
- Signup view (QR entry, 18+ age gate, deposit/donation rules shown before payment)
- Profile (Google or email auth, visibility toggle: public/private)
- Events page (Google Calendar subscribe + hook field)
- Home-page bug/feature form with captcha → private GitHub repo
- Sponsor preview viewport (how ad renders with pending info)
