# @avclub/config

Shared configuration.

## Values
- Payment methods: credit card, Apple Pay, Google Pay
- Age gate: 18+
- Deposit: $10 (refundable, automatic by method)
- Donation: same method as deposit, non-refundable
- Memberships: co-sponsorship $200/mo, supporter $50/mo
- Phase timings: Checkin, Meet & Greet 15m, Sponsor Time 5m, Show & Tell lightning, Build 2h, Intermission 10m, Review 5m, Vote 3m, Award 5m, Party 3h
- Party Time forward URL: https://drawing.grok.me
- **Event banners:** type is always a variation of Open Sans (Regular / Medium / SemiBold / Bold / ExtraBold / Condensed / Italic). Banners include emoji matching the phase marks in the root README. Sponsor media sits under the banner type, never replaces the family.
